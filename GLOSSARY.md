# Каталог книг магазина

Каталог описывает книги магазина, выпустившие их издательства, цены и доступные для продажи остатки. Термины ниже используются в обсуждениях, интерфейсе и коде в одном значении.

## Language

**Книга**:
Сущность книги в магазине, выпущенной определённым **издательством**. Одна книга в каталоге может иметь несколько доступных для продажи **экземпляров**.
_Avoid_: экземпляр (когда речь о записи каталога)

**Экземпляр**:
Отдельная физическая копия **книги**.
_Avoid_: книга (когда речь об отдельной физической копии)

**Автор**:
Создатель текста **книги**.

**Название книги**:
Название, под которым **книга** представлена в каталоге магазина.

**Издательство**:
Организация, которая подготовила и выпустила **книгу**.
_Avoid_: издание (когда речь об организации)

**Издание**:
Выпуск **книги** **издательством**. В текущем каталоге не выделено в отдельную сущность.
_Avoid_: издательство (когда речь о выпуске книги)

**Год написания**:
Год, когда была написана **книга**, а не когда её выпустило **издательство**.
_Avoid_: год (без уточнения), год издания

**Год издания**:
Год, когда **издательство** выпустило **книгу**.
_Avoid_: год (без уточнения), год написания

**Цена**:
Цена одного **экземпляра** **книги** в условной, выдуманной валюте без привязки к реальным валютам.
_Avoid_: стоимость остатка

**Доступный остаток**:
Количество **экземпляров** **книги**, доступных для продажи. Нулевой доступный остаток означает отсутствие экземпляров в продаже.
_Avoid_: общее количество экземпляров (без уточнения доступности для продажи)
