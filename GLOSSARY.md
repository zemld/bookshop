# Словарь предметной области

Приложение ведёт каталог книг магазина и издательств. Этот словарь закрепляет значения терминов, используемых в интерфейсе, API и коде.

## Основные понятия

| Термин | Имя в коде / API | Значение |
|---|---|---|
| Книга | `Book` | Сущность книги в магазине. Содержит сведения об авторе, названии, годе написания, издательстве, годе издания, цене и доступном остатке. Одна запись книги не равна одному физическому экземпляру. |
| Автор | `author` | Автор книги. Хранится как текстовое поле книги, а не как отдельная сущность. |
| Название книги | `name` в `Book` | Название, под которым книга представлена в каталоге магазина. |
| Год написания | `year` | Год, когда была написана книга. Не означает год её выпуска издательством. |
| Издательство | `Publisher` | Организация, которая подготовила и выпустила книгу. Представлено отдельной сущностью с идентификатором и названием. |
| Название издательства | `name` в `Publisher` | Название организации, выпускающей книги. |
| Год издания | `publicationYear` | Год, когда издательство выпустило книгу. |
| Цена | `price` | Цена одного экземпляра книги в условной, выдуманной валюте. Привязки к реальной валюте нет. В API задаётся целым числом. |
| Доступный остаток | `quantity` | Количество экземпляров книги, доступных для продажи. Нулевой остаток означает, что доступных для продажи экземпляров нет. |
| Идентификатор | `id` | Уникальный идентификатор записи книги или издательства в формате UUID. |
| Идентификатор издательства | `publisherId` | Ссылка книги на издательство, которое её выпустило. Содержит UUID записи издательства. |

## Различия между терминами

- **Книга и экземпляр.** Книга — запись каталога магазина. Экземпляр — отдельная физическая копия книги. Число доступных для продажи экземпляров хранится в остатке.
- **Издательство и издание.** Издательство — организация, выпускающая книгу. Издание — выпуск книги издательством, а не название организации. Отдельной сущности издания в текущей модели нет.
- **Год написания и год издания.** Первый относится к написанию книги, второй — к её выпуску издательством. Эти поля имеют разный смысл, даже если их значения совпадают.
- **Цена и стоимость остатка.** Цена относится к одному экземпляру, а не ко всем экземплярам книги в магазине.
