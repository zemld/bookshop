# SLI, SLO и SLA

## SLI

| Индикатор | Расчёт | Источник |
|---|---|---|
| Доступность каталога | Успешные проверки / все выполненные проверки | Пробер: `GET /books` через frontend каждые 30 с. Успех — HTTP 200 за ≤ 3 с, без редиректов и проверки тела |
| Скорость чтения каталога | Успешные чтения за ≤ 300 мс / все успешные чтения | Гистограмма длительности backend-запросов `GET /books` с HTTP 200 |
| Успешность записи | Успешные запросы записи / все учитываемые запросы записи | Счётчик backend-запросов `createBook`, `updateBook`, `createPublisher`, `updatePublisher` по операции и HTTP-статусу |

Успех записи определяется HTTP-контрактом операции. Ожидаемые ошибки пользовательских данных исключаются по явно заданным правилам, а не по всем статусам 4xx.

## SLO

Окно оценки — скользящие 30 дней.

| Индикатор | Цель |
|---|---|
| Доступность каталога | ≥ 99,5% успешных проверок |
| Скорость чтения каталога | ≥ 95% успешных чтений за ≤ 300 мс |
| Успешность записи | ≥ 99% успешных учитываемых запросов записи |

## SLA

Окно оценки — календарный месяц в UTC.

| Индикатор | Обязательство |
|---|---|
| Доступность каталога | ≥ 99% успешных проверок |
| Скорость чтения каталога | ≥ 95% успешных чтений за ≤ 300 мс |
| Успешность записи | ≥ 99% успешных учитываемых запросов записи |

Общее SLA выполнено при соблюдении всех трёх обязательств. Проценты не усредняются и не перемножаются.

При подтверждённом нарушении команда публикует отчёт и план корректирующих действий в течение трёх рабочих дней. Финансовая компенсация не предусмотрена.

## Условия измерения

- Blackbox Exporter проверяет `http://frontend.bookshop.svc:8081/books` из namespace `metrics` внутри Kubernetes; доступность из интернета не проверяется.
- Плановое обслуживание и развёртывания не исключаются из расчёта.
- При отсутствии событий или неполных измерениях выполнение соответствующего обязательства не подтверждено; отсутствие данных не означает успех.
- Для остальных SLI необходимо определить исключения ошибок записи и обеспечить границу bucket 300 мс.
